## 🔧 配置优先级说明

根据代码分析，配置的加载优先级为：

```
环境变量 > config.yaml > 数据库默认值
```

### 配置加载流程

1. **系统启动时**：首先从 `config.yaml` 文件加载基础配置
2. **环境变量覆盖**：如果设置了对应的环境变量，会覆盖 `config.yaml` 中的值
3. **数据库初始化**：将最终的配置值（经过环境变量覆盖后）存储到数据库的 `system_configs` 表中
4. **运行时读取**：系统运行时从数据库中读取配置，确保配置的一致性

## 🔐 敏感字段加密状态

目前已实现自动加密的敏感字段：
- ✅ `aliyun_password` - 阿里云密码
- ✅ `gitee_password` - Gitee密码  
- ✅ `gitee_token` - Gitee访问令牌
- ✅ `github_token` - GitHub访问令牌

## 🆕 新增配置字段说明

### Git分支配置
- `gitee_branch` - Gitee仓库分支名，默认为 `main`
- `github_branch` - GitHub仓库分支名，默认为 `main`

### Git本地路径配置
- `gitee_local_path` - Gitee仓库本地克隆路径，默认为 `./temp/gitee_repo`
- `github_local_path` - GitHub仓库本地克隆路径，默认为 `./temp/github_repo`

这些新增字段支持通过环境变量和config.yaml进行配置，遵循相同的优先级规则。

### 加密机制说明

- **加密算法**：AES-256-GCM
- **存储格式**：`ENC:` + Base64编码的加密数据
- **密钥管理**：优先使用环境变量 `ENCRYPTION_KEY`，支持密钥派生
- **自动处理**：敏感字段在存储时自动加密，读取时自动解密
