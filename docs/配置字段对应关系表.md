## 🔧 配置优先级说明

根据代码分析，配置的加载优先级为：

```
环境变量 > config.yaml > 数据库默认值
```

### 配置加载流程

1. **系统启动时**：首先从 `config.yaml` 文件加载基础配置
2. **环境变量覆盖**：如果设置了对应的环境变量，会覆盖 `config.yaml` 中的值
3. **数据库初始化**：将最终的配置值（经过环境变量覆盖后）存储到数据库的 `system_configs` 表中
4. **运行时读取**：系统运行时从数据库中读取配置，确保配置的一致性

## 🔐 敏感字段加密状态

目前已实现自动加密的敏感字段：
- ✅ `aliyun_password` - 阿里云密码
- ✅ `gitee_password` - Gitee密码  
- ✅ `gitee_token` - Gitee访问令牌
- ✅ `github_token` - GitHub访问令牌

### 加密机制说明

- **加密算法**：AES-256-GCM
- **存储格式**：`ENC:` + Base64编码的加密数据
- **密钥管理**：优先使用环境变量 `ENCRYPTION_KEY`，支持密钥派生
- **自动处理**：敏感字段在存储时自动加密，读取时自动解密

## 🧪 测试配置优先级

根据项目规则，可以通过以下方式测试配置的优先级：

### 1. 仅设置 config.yaml
```bash
# 不设置环境变量，只在 config.yaml 中配置
# 数据库中的值应该来自 config.yaml
```

### 2. 仅设置环境变量
```bash
# 设置环境变量，不在 config.yaml 中配置
export GITEE_TOKEN="gitee-token-value"
# 数据库中的值应该来自环境变量
```

### 3. 同时设置两者
```bash
# 同时设置环境变量和 config.yaml
export GITEE_TOKEN="env-token-value"
# 数据库中的值应该来自环境变量（优先级更高），忽略 config.yaml 中的值
```

### 环境变量操作命令

在 Ubuntu 22.04 环境中：

```bash
# 设置环境变量
export GITEE_TOKEN="gitee-token-value"

# 取消环境变量
unset GITEE_TOKEN
```

## 🔍 验证配置

### 清空数据库并重新初始化
```bash
# 1. 清空 system_configs 表
mysql -h 192.168.0.180 -P 3307 -u root -pLipanxiang@1102 -e "USE docker_sync; DELETE FROM system_configs;"

# 2. 重启后端服务（会自动初始化默认配置）
lsof -i:8080 | awk 'NR>1{print $2}' | xargs kill -9
make backend

# 3. 检查配置是否正确存储
mysql -h 192.168.0.180 -P 3307 -u root -pLipanxiang@1102 -e "USE docker_sync; SELECT config_key, config_value FROM system_configs ORDER BY config_key;"
```
